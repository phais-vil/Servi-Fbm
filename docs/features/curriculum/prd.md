# Product Requirements Document (PRD)
## ระบบจัดการหลักสูตร (Curriculum & Programs)

### 1. วัตถุประสงค์ (Objective)
เพื่อเป็นระบบบริหารจัดการและเผยแพร่ข้อมูลหลักสูตรการศึกษาของคณะ (ระดับปริญญาตรี ปริญญาโท ปริญญาเอก และหลักสูตรประกาศนียบัตร) สำหรับนักเรียน ผู้ปกครอง และบุคคลภายนอกใช้ในการศึกษาข้อมูลการรับเข้าเรียน แผนการเรียน รายละเอียดวิชา ค่าธรรมเนียมการศึกษา และโอกาสทางอาชีพ พร้อมระบบบริหารจัดการข้อมูลหลักสูตรหลังบ้านสำหรับฝ่ายวิชาการและผู้บริหาร

### 2. กลุ่มผู้ใช้งาน (User Personas & Roles)
1. **บุคคลภายนอก / ผู้สนใจสมัครเรียน / นิสิต (Public Visitor / Prospective Student / Student):**
   - ค้นหาและดูรายละเอียดหลักสูตรแยกตามระดับการศึกษา (ตรี, โท, เอก, ประกาศนียบัตร)
   - ศึกษารายละเอียดวุฒิการศึกษาที่ได้รับ จำนวนหน่วยกิต ระยะเวลาการศึกษา และค่าเทอม
   - ดูโครงสร้างแผนการศึกษา (Study Plan) และโอกาสในการประกอบอาชีพ (Career Paths)
   - ดาวน์โหลดเอกสารมคอ.2 หรือเล่มหลักสูตร
2. **อาจารย์ประจำหลักสูตร / หัวหน้าสาขา (Curriculum Chair / Program Director):**
   - ดูข้อมูลและตรวจสอบความถูกต้องของแผนการเรียนและวิชาในหลักสูตร
3. **เจ้าหน้าที่ฝ่ายบริการการศึกษา / ผู้ดูแลระบบ (Academic Affairs / Admin):**
   - เพิ่ม ปรับปรุง แก้ไข และเปิด/ปิดสถานะการรับสมัครของแต่ละหลักสูตร
   - จัดการโครงสร้างหน่วยกิต ข้อมูลค่าธรรมเนียม และรายละเอียดวิชา
   - เชื่อมโยงหลักสูตรเข้ากับภาควิชา/สาขาวิชา (Department)

### 3. Functional Requirements
- **FR-01 (Public Program Directory):** แสดงรายการหลักสูตรทั้งหมดที่เปิดสอน แยกตามระดับปริญญา (Bachelor, Master, Doctoral, Diploma)
- **FR-02 (Program Detail View):** แสดงหน้ารายละเอียดหลักสูตรอย่างครบถ้วน (วุฒิการศึกษา, หน่วยกิตรวม, ระยะเวลาเรียน, ค่าใช้จ่าย, จุดเด่นหลักสูตร, แผนการเรียน, สายอาชีพ)
- **FR-03 (Search & Filter):** ค้นหาหลักสูตรตามชื่อ (ไทย/อังกฤษ), รหัสหลักสูตร, ภาควิชา, หรือระดับการศึกษา
- **FR-04 (Admin Program Management):** จัดการเพิ่ม ลบ แก้ไข ข้อมูลหลักสูตรผ่าน DataTable และ Form Dialog
- **FR-05 (Department Linkage):** เชื่อมโยงหลักสูตรเข้ากับภาควิชาต้นสังกัด (`Department`)
- **FR-06 (Multi-tenancy):** ข้อมูลหลักสูตรต้องแยกตาม `tenantId` อย่างปลอดภัย
- **FR-07 (Audit Logging):** บันทึกประวัติการสร้าง แก้ไข และลบหลักสูตรลงใน `audit_logs`

### 4. Non-Functional Requirements & UX
- **Performance:** หน้าแสดงรายการและหน้ารายละเอียดหลักสูตรต้องโหลดเร็วด้วย Server-Side Rendering (SSR)
- **Security:** สิทธิ์การจัดการหลักสูตร (`curriculum:read`, `curriculum:manage`) ต้องตรวจสอบอย่างเคร่งครัด
- **i18n:** รองรับ 2 ภาษา (ไทย และ อังกฤษ)
- **Design System:** ใช้คอมโพเนนต์ตามมาตรฐาน Liyon System อย่างเคร่งครัด
