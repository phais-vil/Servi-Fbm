# Product Requirements Document (PRD)
## ระบบจัดการข่าวสารประชาสัมพันธ์ (News & Announcements)

### 1. วัตถุประสงค์ (Objective)
เพื่อเป็นศูนย์กลางในการเผยแพร่ข่าวสาร ประชาสัมพันธ์ ข่าวกิจกรรม ทุนการศึกษา และประกาศสำคัญของคณะสู่สาธารณะ (นิสิต คณาจารย์ บุคลากร และบุคคลภายนอก) พร้อมระบบจัดการหลังบ้าน (Admin Console) สำหรับเจ้าหน้าที่ประชาสัมพันธ์และผู้บริหารในการสร้าง ตรวจสอบ เผยแพร่ และปักหมุดข่าวสารสำคัญ

### 2. กลุ่มผู้ใช้งาน (User Personas & Roles)
1. **บุคคลภายนอก / นิสิต (Public Visitor / Student - Guest Role):**
   - เข้าชมข่าวสารล่าสุด
   - ค้นหาข่าวตามคำสำคัญ และกรองตามหมวดหมู่ (วิชาการ, กิจกรรม, ทุนการศึกษา, ทั่วไป)
   - ดูข่าวปักหมุดเด่นบน Hero Carousel
   - อ่านเนื้อหาข่าวฉบับเต็ม พร้อมรูปภาพและไฟล์แนบ
2. **เจ้าหน้าที่ประชาสัมพันธ์ (PR Staff):**
   - ร่างข่าวสารใหม่ (Draft)
   - กำหนดหมวดหมู่, อัปโหลดภาพหน้าปก (Cover Image), ใส่รูปภาพประกอบ และแนบเอกสาร
   - แก้ไขข่าวที่ตนเองสร้างหรือรับผิดชอบ
3. **ผู้บริหาร / ผู้ดูแลระบบ (Executive / Super Admin):**
   - อนุมัติและเปลี่ยนสถานะข่าวเป็นเผยแพร่ (PUBLISHED)
   - ปักหมุดข่าวเด่น (Pinned) สูงสุด 5 ข่าว เพื่อแสดงผลบน Banner แรกของหน้าเว็บ
   - ถอดถอนข่าว (ARCHIVED) หรือลบข่าวที่ไม่เหมาะสม

### 3. Functional Requirements
- **FR-01 (Public News Feed):** แสดงรายการข่าวที่สถานะ `PUBLISHED` เรียงจากล่าสุดไปเก่าสุด และนำข่าวปักหมุด (`isPinned`) ขึ้นก่อน
- **FR-02 (Category Filtering & Search):** รองรับการกรองข่าวตามหมวดหมู่ (`ACADEMIC`, `EVENT`, `SCHOLARSHIP`, `GENERAL`) และค้นหาแบบ Text Search ในชื่อเรื่องและเนื้อหา
- **FR-03 (News Detail & SEO Slug):** เข้าถึงหน้ารายละเอียดข่าวผ่าน URL สวยงาม (SEO Friendly Slug เช่น `/news/faculty-open-house-2026`)
- **FR-04 (Admin News Management):** เจ้าหน้าที่สามารถสร้าง แก้ไข เปลี่ยนสถานะ และลบข่าวผ่านตารางข้อมูลพร้อม Action Dialog
- **FR-05 (Pinning System):** สามารถปักหมุดข่าวสำคัญได้ไม่เกิน 5 ข่าวต่อ Tenant
- **FR-06 (Multi-tenancy):** ข้อมูลข่าวสารต้องแยกตาม `tenantId` อย่างเด็ดขาด
- **FR-07 (Audit Logging):** ทุกการสร้าง แก้ไข เผยแพร่ ปักหมุด หรือลบข่าว ต้องบันทึกลง `audit_logs`

### 4. Acceptance Criteria
- [ ] นิสิต/บุคคลทั่วไป สามารถเข้าดูหน้ารวมข่าว `/news` และหน้ารายละเอียด `/news/[slug]` ได้โดยไม่ต้องล็อกอิน
- [ ] ข่าวที่มีสถานะ `DRAFT` หรือ `ARCHIVED` จะต้องไม่แสดงบนหน้า Public Portal
- [ ] เมื่อสร้างข่าวใหม่ ระบบจะคำนวณ `slug` อัตโนมัติจากชื่อข่าวและ timestamp หากไม่มีการระบุ
- [ ] เจ้าหน้าที่ที่มีสิทธิ์ `news:manage` สามารถจัดการข่าวในระบบหลังบ้าน `/(admin)/news` ได้
- [ ] การลบข่าว หรือเปลี่ยนสถานะข่าว จะต้องผ่านการตรวจสอบสิทธิ์ `news:delete` หรือ `news:publish`
- [ ] หน้าเว็บรองรับสองภาษา (ภาษาไทยและภาษาอังกฤษ) ผ่านระบบ i18n
