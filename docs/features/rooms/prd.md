# Product Requirements Document (PRD)
## ระบบจองห้องประชุมประจำคณะ (Faculty Meeting Room Booking)

### 1. วัตถุประสงค์ (Objective)
เพื่อบริหารจัดการห้องประชุมส่วนกลาง ห้องสัมมนา และห้องปฏิบัติการประชุมของคณะ ให้สามารถใช้งานทรัพยากรร่วมกันได้อย่างมีประสิทธิภาพสูงสุด ป้องกันปัญหาการจองซ้ำซ้อน (Booking Conflict) และช่วยให้อาจารย์ บุคลากร และนิสิตตรวจสอบตารางความพร้อมใช้งาน (Availability) และจองห้องล่วงหน้าผ่านระบบดิจิทัล พร้อมระบบอนุมัติการใช้ห้องสำหรับเจ้าหน้าที่งานอาคารสถานที่

### 2. กลุ่มผู้ใช้งาน (User Personas & Roles)
1. **ผู้ขอใช้ห้อง (Requester - คณาจารย์ / บุคลากร / ตัวแทนนิสิต):**
   - ตรวจสอบรายการห้องประชุม ขนาดความจุ อุปกรณ์ประจำห้อง และรูปถ่ายห้อง
   - ดูตารางการใช้งานห้อง (Availability Schedule) แต่ละห้องในแต่ละวัน
   - ยื่นคำขอจองห้องประชุม ระบุวัน เวลา วัตถุประสงค์ จำนวนผู้เข้าร่วม และอุปกรณ์เพิ่มเติม
   - ตรวจสอบสถานะการจองของตนเอง และยกเลิกการจองได้หากไม่ได้ใช้งาน
2. **เจ้าหน้าที่งานอาคารสถานที่ / ผู้ดูแลห้องประชุม (Room Manager / Admin):**
   - จัดการข้อมูลห้องประชุม (เพิ่ม ลบ แก้ไข เปิด/ปิดปรับปรุงห้อง)
   - ตรวจสอบรายการจองห้องที่ขอเข้ามา และดำเนินการอนุมัติ (Confirm) หรือปฏิเสธ (Reject)
   - ตรวจสอบภาพรวมการใช้งานห้องประชุมของทั้งคณะ

### 3. Functional Requirements
- **FR-01 (Room Directory & Details):** แสดงรายการห้องประชุม ขนาดความจุ อาคาร ชั้น สิ่งอำนวยความสะดวก (โปรเจกเตอร์, ระบบ Hybrid Meeting, ไมโครโฟน)
- **FR-02 (Availability Calendar):** ตรวจสอบตารางการจองของแต่ละห้อง ป้องกันการจองในเวลาที่ทับซ้อนกัน (Overlap Prevention)
- **FR-03 (Booking Submission):** ยื่นจองห้องประชุมออนไลน์ พร้อมบันทึกจำนวนคนและอุปกรณ์ที่ต้องการ
- **FR-04 (Admin Booking Management):** อนุมัติการจอง (Confirm) หรือปฏิเสธการจอง (Reject) พร้อมบันทึกเหตุผล
- **FR-05 (Multi-Tenancy):** ข้อมูลห้องและการจองแยกตาม `tenantId`
- **FR-06 (Audit Logging):** บันทึกประวัติการสร้างห้องและอนุมัติการจองลง `audit_logs`

### 4. Non-Functional Requirements & UX
- **No Overlapping:** ระบบต้องมี Validation ตรวจสอบช่วงเวลาซ้ำซ้อนในระดับฐานข้อมูลและ Service layer
- **Security:** ตรวจสอบสิทธิ์ `rooms:book` สำหรับการจอง และ `rooms:manage` สำหรับการจัดการห้องและอนุมัติ
- **i18n:** รองรับภาษาไทยและภาษาอังกฤษ
- **Design System:** ใช้ Liyon Design System
