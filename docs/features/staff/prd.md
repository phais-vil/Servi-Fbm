# Product Requirements Document (PRD)
## ระบบจัดการบุคลากร (Staff & Faculty Directory)

### 1. วัตถุประสงค์ (Objective)
เพื่อเป็นไดเรกทอรีศูนย์กลางในการจัดเก็บ ค้นหา และแสดงข้อมูลประวัติของคณาจารย์และบุคลากรสายสนับสนุนประจำคณะ ให้แก่นักเรียน นักศึกษา ผู้ปกครอง และบุคคลภายนอกได้สืบค้นข้อมูลความเชี่ยวชาญ ผลงานทางวิชาการ และช่องทางการติดต่อ พร้อมระบบบริหารจัดการหลังบ้านสำหรับเจ้าหน้าที่ HR และอาจารย์ในการอัปเดตข้อมูลตนเอง

### 2. กลุ่มผู้ใช้งาน (User Personas & Roles)
1. **บุคคลภายนอก / นิสิต (Public Visitor / Student - Guest):**
   - ค้นหารายชื่อคณาจารย์และบุคลากรตามภาควิชา/หน่วยงาน
   - ค้นหาด้วยชื่อ ตำแหน่งทางวิชาการ หรือคีย์เวิร์ดความเชี่ยวชาญ (Expertise tags)
   - ดูข้อมูลประวัติการศึกษา ห้องพักอาจารย์ เบอร์โทรศัพท์ และอีเมลติดต่อ
2. **คณาจารย์ / บุคลากร (Faculty / Staff Member):**
   - ดูและแก้ไขข้อมูลประวัติส่วนตัว วุฒิการศึกษา สาขาความเชี่ยวชาญ และช่องทางติดต่อของตนเอง
3. **เจ้าหน้าที่งานบุคคล / ผู้ดูแลระบบ (HR Staff / Admin):**
   - เพิ่ม ลบ แก้ไข ข้อมูลบุคลากรทั้งหมด
   - กำหนดสังกัดภาควิชา/สาขาวิชา
   - จัดลำดับการแสดงผล (orderIndex) ตามลำดับอาวุโสและตำแหน่งทางวิชาการ
   - เปิด/ปิด สถานะการปฏิบัติงาน (Active / Inactive / On Leave)

### 3. Functional Requirements
- **FR-01 (Public Staff Directory):** แสดงรายชื่อบุคลากรที่สถานะ `isActive: true` แยกตามภาควิชา (`Department`)
- **FR-02 (Search & Filtering):** รองรับการค้นหาด้วยชื่อ-นามสกุล (ทั้งภาษาไทยและภาษาอังกฤษ), ตำแหน่ง, และแท็กความเชี่ยวชาญ
- **FR-03 (Staff Profile Detail):** แสดงการ์ดและหน้าข้อมูลประวัติบุคลากรแบบละเอียด ประกอบด้วยภาพถ่าย วุฒิการศึกษา ห้องทำงาน อีเมล และเบอร์โทร
- **FR-04 (Department Management):** จัดการข้อมูลภาควิชา/หน่วยงานต้นสังกัด
- **FR-05 (Admin Staff Management):** เพิ่ม/แก้ไข/ระงับสถานะบุคลากรผ่านตารางข้อมูลฝั่ง Admin
- **FR-06 (Multi-tenancy):** ข้อมูลบุคลากรและภาควิชาต้องแยกตาม `tenantId` อย่างเด็ดขาด
- **FR-07 (Audit Logging):** บันทึกการเปลี่ยนแปลงข้อมูลบุคลากรลง `audit_logs`

### 4. Acceptance Criteria
- [ ] บุคคลทั่วไปสามารถเข้าดูไดเรกทอรีที่ `/staff` ได้โดยไม่ต้องล็อกอิน
- [ ] บุคลากรที่สถานะ `isActive: false` จะไม่ปรากฏในหน้า Public Portal
- [ ] หน้า Admin `/admin/staff` มีสิทธิ์ตรวจสอบ `staff:read` และ `staff:manage`
- [ ] รองรับการแสดงผลทั้งภาษาไทยและภาษาอังกฤษตามระบบ i18n
